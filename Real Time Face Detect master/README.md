# Real Time Face & Emotion Detection

A real-time face and emotion detection web app using Face API and JavaScript.

## Features
- Real-time webcam face detection
- Emotion recognition
- Live prediction percentages

## Tech Stack
- HTML
- CSS
- JavaScript
- Face API.js

## Run Locally
npm install
live-server
