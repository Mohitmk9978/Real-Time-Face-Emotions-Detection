# Real Time Face & Emotion Detection 😃

A real-time face and emotion detection web app built using JavaScript and Face API.js.  
It detects faces through webcam and predicts emotions with live confidence scores.

## 🚀 Features
- Real-time face detection
- Emotion recognition
- Live webcam support
- Fast and responsive UI

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript
- Face API.js
